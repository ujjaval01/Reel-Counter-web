# ScrollCount Official Website

Premium startup landing page for **ScrollCount**, an Android digital-wellbeing application that helps users track short-video scrolling across Instagram Reels, YouTube Shorts, and Facebook Reels.

## 🚀 Quick Start

1. Clone or unzip this repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run local dev server:
   ```bash
   npm run dev
   ```
4. Build production bundle:
   ```bash
   npm run build
   ```

## 🛠 Tech Stack

- **React 18** with **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (icons)

## 🌐 Deploy to GitHub Pages

Run:
```bash
npm install -g gh-pages
npm run build
npx gh-pages -d dist
```
